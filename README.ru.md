# FxmlKino для телевизоров Samsung

[English version](README.md)

**FxmlKino** показывает два киносайта, [HDRezka](https://kz.rezka.biz/) и [Kinogo](https://sim.kinogo.tm/),
на телевизорах Samsung Smart TV в виде страниц [Fork browser](https://wiki.forkbrowser.top/wiki/FXML) (FXML).

- Без рекламы и без регистрации.
- Выбор сезона, серии и озвучки, а также качества вплоть до 1080p, как на сайте.
- Сайты читает **сам телевизор**: после установки не нужны ни компьютер, ни сервер. Если сайты
  открываются у вас на компьютере, то должны работать и на телевизоре.

Проверено на UE65TU7500 (2020, Tizen 5.5).

## Установка на телевизор

Уже пользуетесь [TizenBrew](https://github.com/reisxd/TizenBrew)? Тогда добавьте FxmlKino прямо в
него, без компьютера: см. [FxmlKino-TizenBrew](https://github.com/bizhuka/FxmlKino-TizenBrew).

Нужен компьютер с Windows в той же домашней сети, что и телевизор. Больше ничего ставить не надо.

1. **Скачайте** этот репозиторий: **Code → Download ZIP**, затем распакуйте.
2. **Включите на телевизоре режим разработчика** (один раз для каждого ТВ):
   1. Откройте **«Приложения»** (Home → Приложения / Apps).
   2. Наберите на пульте **1 2 3 4 5**. На Smart-пульте цифры вызываются кнопкой **123**.
   3. **Developer mode**: **On** (Вкл.), **Host PC IP**: IP вашего компьютера. Установщик
      показывает его вверху меню.
   4. Перезагрузите ТВ: держите кнопку питания, пока он не выключится и не включится снова.
3. **На компьютере** дважды щёлкните **`install.bat`** в распакованной папке. Выберите **1**, затем
   свой ТВ. Установщик найдёт телевизор, установит **FxmlKino** и запустит его.

Можно установить и сразу на все готовые телевизоры (пункт 3).

### Телевизоры 2022 года и новее (Tizen 7+)

Телевизоры 2017–2021 годов (Tizen 3–6.5) ставят FxmlKino без ограничений. Телевизоры 2022 года и
новее (Tizen 7+) принимают только приложения, в сертификате Samsung которых указан их **ID
устройства**. Установщик определяет версию Tizen и на Tizen 7+ сохраняет ID телевизора в файл
**`devices.txt`** в своей папке. Отправьте этот файл автору (создайте issue в этом репозитории): ID добавят в
сертификат и опубликуют здесь новую версию.

## Файлы

| Файл | Назначение |
|---|---|
| `install.bat` | Начните с него: дважды щёлкните. |
| `install.ps1`, `tv-common.ps1` | Установщик: находит телевизоры Samsung в сети, проверяет режим разработчика, ставит приложение, запускает его и записывает ID устройств. |
| `FxmlKino.wgt` | Приложение для ТВ до Tizen 7 (2017–2021), подписанное так же, как [TizenBrew](https://github.com/reisxd/TizenBrew) подписывает свою сборку для них. |
| `FxmlKino-tizen7.wgt` | Приложение для Tizen 7+ (2022+), подписанное сертификатом Samsung для перечисленных ТВ. |
| `sdb.exe` | Утилита Samsung из Tizen SDK, через которую установщик связывается с ТВ. |
| `README.txt` | Краткая инструкция. |

Этот репозиторий собирается инструментом автора. Исходный код приложения здесь не публикуется.
