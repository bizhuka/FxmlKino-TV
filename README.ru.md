# FxmlKino для телевизоров Samsung

[English version](README.md)

**FxmlKino** показывает два киносайта, [HDRezka](https://kz.rezka.biz/) и [Kinogo](https://sim.kinogo.tm/),
на телевизорах Samsung Smart TV в виде страниц [Fork browser](https://wiki.forkbrowser.top/wiki/FXML) (FXML).

- Без рекламы и без регистрации.
- Выбор сезона, серии и озвучки, а также качества вплоть до 1080p, как на сайте.
- Сайты читает **сам телевизор**: после установки не нужны ни компьютер, ни сервер. Если сайты
  открываются у вас на компьютере, то должны работать и на телевизоре.

Проверено на UE65TU7500 (2020, Tizen 5.5).

## Установка на телевизор

Есть три способа. Для любого из них один раз нужен **режим разработчика** на телевизоре (см.
[Режим разработчика](#режим-разработчика) ниже).

| Способ | Телевизоры | Примечание |
|---|---|---|
| **1. TizenBrew Installer** (рекомендуется) | любые Samsung с 2017 года, включая 2022+ | Одна программа на компьютере или Android-телефоне; сертификат для **вашего** ТВ она создаёт сама. |
| 2. Модуль TizenBrew | любой ТВ, где уже стоит TizenBrew | Без компьютера и без подписи. |
| 3. `install.bat` из этого репозитория | 2017–2021 (Tizen 3–6.5); 2022+ — только если ТВ есть в сертификате автора | Только Windows. |

### 1. TizenBrew Installer (рекомендуется)

1. Включите [режим разработчика](#режим-разработчика), в **Host PC IP** укажите IP компьютера.
2. Скачайте [TizenBrew Installer](https://github.com/reisxd/TizenBrewInstaller/releases/latest) для
   своей системы, запустите его и подключите к телевизору.
3. Выберите установку приложения **с GitHub** и введите:
   ```
   bizhuka/FxmlKino-TV
   ```
   Программа скачает `FxmlKino.wgt` из последнего
   [релиза](https://github.com/bizhuka/FxmlKino-TV/releases/latest) этого репозитория и установит его.
4. На телевизорах 2022 года и новее (Tizen 7+) она попросит войти в учётную запись Samsung и
   создаст сертификат для вашего ТВ: просто следуйте подсказкам на экране.

### 2. Модуль TizenBrew

Если на телевизоре уже есть TizenBrew: нажмите в нём **зелёную** кнопку, выберите **Add GitHub
Module** и введите `bizhuka/FxmlKino-TizenBrew`. Подробнее:
[FxmlKino-TizenBrew](https://github.com/bizhuka/FxmlKino-TizenBrew/blob/main/README.ru.md).

### 3. Установщик для Windows из этого репозитория

1. **Скачайте** этот репозиторий: **Code → Download ZIP**, затем распакуйте.
2. Включите [режим разработчика](#режим-разработчика), в **Host PC IP** укажите IP компьютера.
3. Дважды щёлкните **`install.bat`** в распакованной папке. Выберите **1**, затем свой ТВ.
   Установщик найдёт телевизор, установит **FxmlKino** и запустит его. Пункт 3 ставит сразу на все
   готовые телевизоры.

Телевизоры 2017–2021 годов (Tizen 3–6.5) ставят его без ограничений. Телевизоры 2022 года и новее
(Tizen 7+) примут его, только если их **ID устройства** есть в сертификате Samsung автора.
Установщик сохраняет ID телевизора в **`devices.txt`**: отправьте файл автору (создайте issue
здесь) или используйте способ 1.

### Режим разработчика

Один раз для каждого ТВ:

1. Откройте **«Приложения»** (Home → Приложения / Apps).
2. Наберите на пульте **1 2 3 4 5**. На Smart-пульте цифры вызываются кнопкой **123**.
3. **Developer mode**: **On** (Вкл.), **Host PC IP**: IP компьютера (или телефона), с которого
   ставите. В Windows его показывает команда `ipconfig` (строка «IPv4-адрес»).
4. Перезагрузите ТВ: держите кнопку питания, пока он не выключится и не включится снова.

## Файлы

| Файл | Назначение |
|---|---|
| `install.bat` | Установщик для Windows (способ 3): дважды щёлкните. |
| `install.ps1`, `tv-common.ps1` | Код установщика: находит телевизоры Samsung в сети, проверяет режим разработчика, ставит приложение, запускает его и записывает ID устройств. |
| `FxmlKino.wgt` | Приложение для ТВ до Tizen 7 (2017–2021), подписанное так же, как [TizenBrew](https://github.com/reisxd/TizenBrew) подписывает свою сборку для них. Для ТВ 2022+ TizenBrew Installer переподписывает его сам. Также прикреплено к каждому [релизу](https://github.com/bizhuka/FxmlKino-TV/releases). |
| `FxmlKino-tizen7.wgt` | Приложение для Tizen 7+ (2022+), подписанное сертификатом Samsung автора для перечисленных в нём ТВ. |
| `sdb.exe` | Утилита Samsung из Tizen SDK, через которую установщик связывается с ТВ. |
| `README.txt` | Краткая инструкция. |

Этот репозиторий собирается инструментом автора. Исходный код приложения здесь не публикуется.
