FxmlKino (HDRezka, Kinogo) для телевизоров Samsung
==================================================

Нужно: компьютер с Windows в той же домашней сети, что и телевизор. Больше ничего ставить не надо.

1. На телевизоре включите режим разработчика (один раз для каждого ТВ):
   - Откройте «Приложения» (Home -> Приложения / Apps).
   - Наберите на пульте 1 2 3 4 5 (на Smart-пульте цифры - кнопка 123).
   - Developer mode: On (Вкл.). Host PC IP: IP этого компьютера (install.bat показывает его вверху).
   - Перезагрузите ТВ: держите кнопку питания, пока он не выключится и не включится снова.

2. На компьютере распакуйте эту папку и дважды щёлкните install.bat. Выберите 1, затем свой ТВ.
   Установщик поставит «FxmlKino» и запустит его.

Телевизоры 2017–2021 годов (Tizen 3–6.5) ставят приложение без ограничений. Телевизоры 2022 года
и новее (Tizen 7+) принимают его, только если их ID есть в сертификате: если такой ТВ откажется,
отправьте файл devices.txt из этой папки тому, кто дал вам установщик. Он пришлёт новый.

Файлы: install.bat / install.ps1 (установщик), tv-common.ps1 (общий код), sdb.exe (утилита Samsung
для связи с ТВ), FxmlKino.wgt (приложение для ТВ до Tizen 7),
FxmlKino-tizen7.wgt (приложение для Tizen 7+).
