# FxmlKino на телевизоре Samsung (Tizen)

[English version](INSTALL-SAMSUNG.md) · [Назад к README](README.ru.md)

Используйте **TizenBrew Installer**: он работает на любых Samsung с 2017 года, включая 2022+, и сам
создаёт сертификат для **вашего** телевизора. Один раз нужен **режим разработчика** на ТВ (см. ниже).

1. Включите [режим разработчика](#режим-разработчика), в **Host PC IP** укажите IP компьютера (или
   Android-телефона), с которого будете ставить.
2. Скачайте [TizenBrew Installer](https://github.com/reisxd/TizenBrewInstaller/releases/latest) для своей
   системы, запустите его и подключите к телевизору.
3. Выберите установку приложения **с GitHub** и введите:
   ```
   bizhuka/FxmlKino-TV
   ```
   Программа скачает `FxmlKino.wgt` из последнего
   [релиза](https://github.com/bizhuka/FxmlKino-TV/releases/latest) этого репозитория и установит его.
4. На телевизорах 2022 года и новее (Tizen 7+) она попросит войти в учётную запись Samsung и создаст
   сертификат для вашего ТВ: просто следуйте подсказкам на экране.
5. Запустите **FxmlKino** на телевизоре. Пока запускается парсер, внизу слева на заставке видно
   `FXML: …`, затем открывается портал «FXML Кино».

Обновление: повторите шаг 3, новая версия встанет поверх старой, настройки сохранятся.

## Режим разработчика

Один раз для каждого ТВ:

1. Откройте **«Приложения»** (Home → Приложения / Apps).
2. Наберите на пульте **1 2 3 4 5**. На Smart-пульте цифры вызываются кнопкой **123**.
3. **Developer mode**: **On** (Вкл.), **Host PC IP**: IP компьютера (или телефона), с которого ставите.
   В Windows его показывает команда `ipconfig` (строка «IPv4-адрес»).
4. Перезагрузите ТВ: держите кнопку питания, пока он не выключится и не включится снова.

## Торренты на Samsung

Телевизоры Samsung не дают приложению запустить TorrServer, поэтому в FxmlKino есть свой торрент-клиент,
который отвечает так же, как TorrServer. Когда торрент впервые его попросит, выберите **Установить Fork
Torrserve**: он включится сразу, скачивать ничего не нужно. Фильм хранится только в оперативной памяти
телевизора, пока вы его смотрите (во внутреннюю память ничего не пишется), и другим людям ничего не
раздаётся.
